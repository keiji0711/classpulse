# ClassPulse

ClassPulse is a connected school-management platform for administrators,
teachers, learners, and parents. It includes a web workspace, an Android parent
app, Supabase database migrations and functions, attendance and academic
records, learner assessments, analytics, notes, and push notifications.

## Project structure

- `web/` — school and super-admin web application
- `mobile/` — Android/Expo parent application
- `supabase/` — database migrations and edge functions
- `play-store-assets/` — store listing graphics and screenshots
- `load-test/` — scalability and attendance load tests

Environment files and production credentials are intentionally excluded from
version control. Use the included `.env.example` files for local setup.
